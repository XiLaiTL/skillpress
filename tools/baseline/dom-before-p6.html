skillpress —— 写一份能用的 skill
只解决一件事：这份仓库里的一份 skill 怎么写、怎么验、怎么变成站点上的一页。 下面三条都在内容仓根跑（moobile/ —— skills 就在它下面），而程序是它旁边的兄弟 （../skillpress/，它自己是一个 git 仓库）：
node ../skillpress/bin/skillpress.mjs check # 门：skill 自己（G1–G8） node ../skillpress/bin/skillpress.mjs press # 内容源 → 站点内容包 node ../skillpress/bin/skillpress.mjs verify # 判据：真 Chrome 无头
角色分工（别混）：程序在旁边的 skillpress/（引擎 + 门 + 语法资产； 它单独一个仓库，将来发 npm / moonbit 包）； 内容就是你这种目录（SKILL.md + references/）；站点实例在 skills/skillpress/scripts/.skillpress/（一个"用程序"的 MoonBit 工程）。 整套形状、以及"程序为什么在仓库外面"见 references/layout.md。 中间那条最容易漏：改了任何内容源就必须重跑 `press`，否则站点还是旧内容。 press --check 会红并指出第一处差异 —— 它就是为此存在的。
