组件与写法

moobile 的组件、样式与状态约定：什么时候用内置组件、样式写到哪一层、子节点怎么传。

何时用它

你正在写一个新的 moobile 界面组件，或者发现现有组件"样式不生效 / 子节点没出现"。

规则#

四条硬规矩，违反任意一条都会以"看不出原因"的形式坏掉。

规矩为什么坏掉的样子
样式只走 @style.Style字符串通道让 fontWeight 与 fontSize 在编译期分不开编译过、运行静默不生效
子节点必须是 Array[Html]RN 侧按数组 diff只渲染第一个孩子
事件挂在发起的那一层宿主层不做冒泡补齐点空白处没反应
列表要给 key无 key 时复用错误的行输入框内容串行

一个组件长什么样#

最小可用形状 —— 注意样式是结构化的，不是一段 CSS 文本。

card.mbt moonbit 
/// 一张卡片：标题 + 任意子节点。
pub fn card(title : String, kids : Array[@html.Html]) -> @html.Html {
  @html.div(
    attrs=@html.Attrs::build().styles(
      @style.Style::new()
        .padding(@style.px(12.0))
        .border_radius(10.0)
        .background_color("var(--surface)"),
    ),
    [
      @html.span(attrs=@html.Attrs::build(), title),
      ..kids,
    ],
  )
}

三个容易踩的坑#

  • 样式表是扁平的 —— styles() 只接受 Style，拼字符串会得到一个"看起来对"的 props。
  • flex: 1 会平分 —— 一排里放三个弹性项，空隙会跟控件各拿一半（实测 580/580）。
  • 负号有语义 —— 曾经 i < 0 同时盖住"首页"和"换模式"，顶栏出现两条一样的项。
!
别用 .sort() 排字符串

MoonBit 的 Array::sort() 不是字典序。要排就自己写比较器，用现成的 utf16_compare。
