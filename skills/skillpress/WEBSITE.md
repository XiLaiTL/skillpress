# skillpress —— 改它的人和用它的人

我们相信**文档的形态会变成 skill**（agent 拿来即用的那种），而不再另有一份给人看的 docs ——
所以这个站点的意义就是那批 skill 的**人读侧**：同一份内容，机器读原文，人读这里。

这一份语料是**程序自己**的 skill：两份，一份给**改这套程序的人**，一份给**用它做站点的人**。
它同时是站点的**首页源**，也是**站点的家**（站点工程就住在它的 `scripts/.skillpress/` 里）。

## [先读哪一份](../skillpress-user/SKILL.md)

要用这套工具做站点就看 `skillpress-user`（首页怎么写、配色改哪儿、加一块新构造、怎么验收）；
要改这套程序就看 `skillpress-dev`（三个根、改什么跑哪条门、怎么加判据与诱饵）。
两份的边界只有一条：**写内容的不改引擎，改引擎的不写内容**。
